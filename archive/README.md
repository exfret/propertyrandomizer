# Archived implementations

Inactive implementations are retained here for reference. `unused/` contains the former `lib/unused/` tree, including algorithms that were never ported and retired core implementations. Historical imports inside that tree are preserved; the archive is not a runnable subsystem.

Older code still imported by the randomizer remains maintained under `lib/old-logic/` until the source migration moves it into `src/legacy/`. Active experimental randomizations also remain in their current location. See [Directory structure](../docs/directory-structure.md) for the migration plan.

Archived code is excluded from ordinary source guards. Restore and validate it in a maintained module before using it again.
